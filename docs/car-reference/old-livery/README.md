# Old livery

The team's **earlier** livery — black and red, car number 010, with a white number
roundel on the flank. Same programme, same team, an earlier presentation of the car.

This is not another team's car, and it is not the current car. The current car is
white composite with the hand-painted cobra artwork; see `../from-instagram/`.

Useful for the build story — the earlier stages of the programme happened in this
livery — but it must never be captioned as the car as it races now.
