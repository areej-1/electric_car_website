# Generated images

ChatGPT-generated depictions of the car. **Not photographs.** See the usage rules in
`../IMAGE-PROMPTS.md` — these are safe for concept, atmosphere and page furniture, and
unsafe anywhere a sponsor or an EVGP judge would read them as a photograph of the real car.

Save the generated files here.

## Verify before using

Generated images assert details the model invented. Anything here must be checked against
a real photograph before it drives geometry or ships as fact. Known open question: the
generated top-down shows a two-front / one-rear trike layout, which no real photograph in
`../` confirms or refutes.
